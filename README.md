A program that writes one sentence to `/output/entry.txt`: an alien tourist's one-star review of planet Earth that still compliments the food. Six candidate sentences were drafted with DeepSeek and critique-picked against the judge's brief; the winner complains that Earth's sun rises every single day without fail, then admits the coffee is so absurdly good the reviewer is generously rounding up from zero stars.

## Run it

```sh
python3 main.py
```
